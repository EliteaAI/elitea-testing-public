### The catch worth keeping

I flagged before launch that this was the second write-heavy sub-area in a row and that the
failure mode to watch was **a spec that passes while leaving the environment altered** —
not a red. Review found exactly that: `test_vector_storage_edit.py` set `default_changed = True`
*after* the save it guards, so a flake in the gap skips the default-restore while still
deleting the configuration that default pointed at. Naming the failure mode in the dispatch
is what made the reviewer look for it; a generic "review this" would very plausibly have
passed it, because the test itself is green either way.
