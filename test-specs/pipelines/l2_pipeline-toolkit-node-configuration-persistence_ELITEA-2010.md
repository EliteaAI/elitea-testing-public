## Expected Results
- A Toolkit node can be added to a pipeline via "Add node" → "Toolkit" and configured with an attached toolkit + one of its tools.
- Selecting a Tool populates tool-specific INPUT MAPPING (required/optional) sections with real parameter names for that tool.
- The Query mapping can be set to F-String type with a literal value containing a state-variable placeholder (`{input}`).
- Input/Output tool-agnostic state-variable selects can be configured independently of the mapping.
- Saving persists all of the above; a full reload confirms every field survives unchanged, verified via both the Flow-view canvas and the YAML tab.
- No console errors at any step.
