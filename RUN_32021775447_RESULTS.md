## Key Insights

### 1. Environment Restart May Have Occurred Earlier

The skills test failed with **TimeoutError** (form didn't load), which could indicate:
- Page navigation broke due to earlier restart
- Session state corrupted
- Form rendering blocked

**Different from previous 404 console errors**, but **could still be restart-related** at a different stage.

### 2. Test is Fundamentally Unstable

The test creates 5 skills in a loop, which involves:
- Multiple navigations
- Multiple form loads
- Accumulated state

Any failure in the chain causes the whole test to fail.

### 3. Retry Pattern Needs Expansion

Current patterns trigger on:
- Console errors (404, 502, etc.)
- Connection errors
- WebSocket errors

But NOT on:
- TimeoutError during element wait
- Page navigation failures
- Form load failures

## Recommendations

### Option 1: Add TimeoutError to Retry Patterns (Conservative)

**Rationale:**
- TimeoutError during form load could indicate environment restart
- But it could also indicate slow page load or real bug
- Risk: Masking real product issues

**Implementation:**
```ini
# Add to pytest.ini
--only-rerun="TimeoutError"  # Already exists, but verify it matches
```

**Risk:** HIGH - TimeoutError is generic and could mask real bugs

### Option 2: Mark Test as Flaky (Recommended)

**Rationale:**
- Test has failed in multiple ways across multiple runs
- Retries already happening but not fixing it
- Likely has structural issues (too many steps, accumulated state)

**Implementation:**
```python
@pytest.mark.flaky(reruns=3, reruns_delay=10)
@pytest.mark.blocked  # Or mark as blocked if environment issue
def test_max_five_skills_attach_limit(...):
    ...
```

### Option 3: Fix/Improve the Test (Best Long-term)

**Issues to address:**
1. **Too many steps** - Creates 5 skills in a loop (high failure probability)
2. **No intermediate cleanup** - If one skill creation fails, state is corrupted
3. **Long execution time** - More opportunity for environment changes
4. **Complex setup** - Multiple navigations and form fills

**Improvements:**
```python
# Option A: Split into smaller tests
def test_can_attach_one_skill(...)  # P0
def test_can_attach_five_skills(...)  # P2
def test_cannot_attach_sixth_skill(...)  # P2

# Option B: Add resilience
def test_max_five_skills_attach_limit(...):
    try:
        skill_id = _create_skill(...)
    except TimeoutError:
        logger.warning("Skill creation timed out, retrying...")
        page.reload()
        skill_id = _create_skill(...)
```
